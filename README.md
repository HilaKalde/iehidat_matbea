# חדר כושר פיננסי – יחידת מטבע (HTML)

לומדת HTML של בנק ישראל – חינוך פיננסי, יחידת מטבע. גרסת עבודה לבדיקה לפני המרה ל-Storyline.
מבוססת על התסריט המאושר להפקה ועל הערות בנק ישראל לגרסת ה-Storyline (Review 360), ובנויה על המנוע והעיצוב של יחידת אמצעי תשלום.

## הרצה
פותחים את `index.html` בדפדפן (Chrome / Edge).

## מבנה
- `js/data.js` – כל התוכן (מקור אמת יחיד): מסכים, שאלות, תשובות, משובים, תסריטי סרטונים והערות הפקה.
- `js/app.js` – מנוע הלומדה: במה קבועה 1200×675, מסך = `.screen`.
- `css/style.css`, `css/payments.css` – הסגנון המשותף ליחידות; `css/currency.css` – רכיבים ייעודיים ליחידה.
- `assets/` – נבנה מ"תיקיית נכסים" ומקובץ ה-Storyline הקודם בעזרת `../.claude/prep-assets.ps1`.
- `_tools/test.html` – כלי פיתוח בלבד (הרצת תרגילים אוטומטית לצילומי מסך). לא חלק מהלומדה.

## כלי בדיקה (מחוץ לבמה)
רשימת מעבר לכל מסך, כפתור "📝 הערות" (או מקש N) – הערות הפקה, ההערות שיושמו ותסריטי הסרטונים, וכפתור איפוס התקדמות.
